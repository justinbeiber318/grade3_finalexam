# English 3 Online Test

A simple static online test website for:
ĐỀ KIỂM TRA CUỐI KÌ 2 – ĐỀ 1
MÔN: TIẾNG ANH 3 GLOBAL SUCCESS

## Run locally
Open `index.html` in a browser.

## Add listening audio
Create:
audio/listening.mp3

Then open the site again.

## Add listening tick images
Put the six/eight cropped choice images in:
images/listening/

Use these names so each image has its own tick control:
1a.png, 1b.png, 2a.png, 2b.png, 3a.png, 3b.png, 4a.png, 4b.png

The image choices are rendered in the "Listen and tick" section. Each question
allows one choice to be ticked.

## Put online
Upload the whole folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.

## Important
The supplied PDF does not contain the full question text, images, audio, or answer key in the extracted content. The website therefore leaves those items as editable placeholders rather than inventing them.

Edit the arrays near the bottom of `index.html`:
- listenTickQuestions
- listenYNQuestions
- matchQuestions

Writing answers are displayed exactly from the supplied source and are not auto-graded until the exact answer key is known.
